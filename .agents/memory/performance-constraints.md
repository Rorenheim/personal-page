---
name: Performance without visual tradeoffs
description: Preserve the portfolio's videos, animations, quality, and actual UX during performance work.
---

The user wants a smooth, stable experience on lower-end devices without sacrificing animations or quality. Videos and animations must be preserved, and performance optimization must not change the actual UX.

**Why:** The user explicitly rejected sacrificing animations and quality to improve performance.

**How to apply:** Optimize implementation work and redundant processing first. Do not remove effects, lower media quality or rendering resolution, or alter visible animation/playback behavior as a performance shortcut.
